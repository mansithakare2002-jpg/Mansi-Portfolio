# Mansi Thakre | Data Analyst Portfolio

A personal portfolio website showcasing my skills, projects and education as a fresher Data Analyst.

## About

I am an aspiring Data Analyst with a strong foundation in Python, SQL and data visualization. My background is in Electronics and Communication Engineering, and I moved into data through hands-on projects in machine learning, generative AI and dashboarding.

## Features

- Clean, professional single-page design
- Sections for About, Skills, Projects, Education and Contact
- Responsive layout for mobile, tablet and desktop
- Automatic light and dark mode based on device settings
- Keyboard-friendly navigation and reduced-motion support
- No frameworks or build step: one self-contained HTML file

## Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/<mansi thakre>/<Mansi-Portfolio>.git
   ```
2. Open the folder and double-click `index.html` to view it in your browser.

## Deploy

### GitHub Pages

1. Push the files to a GitHub repository.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site will be live at `https://<your-username>.github.io/<your-repo-name>/`.

### Vercel

1. Sign in to [vercel.com](https://vercel.com) with your GitHub account.
2. Click **Add New > Project** and import this repository.
3. Leave the framework preset as **Other** and click **Deploy**.
